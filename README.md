# HTML工具集

一个基于纯HTML/CSS/JavaScript开发的一站式工具平台，提供多种实用工具，支持多用户管理和权限控制。

## 功能特性

- 🔐 **用户认证系统** - 支持多用户登录，管理员和普通用户权限分离
- 🛠️ **工具管理** - 管理员可以添加、编辑、删除工具
- 👥 **用户管理** - 管理员可以创建用户、重置密码、管理权限
- 🔒 **安全会话** - 页面关闭自动退出，支持会话超时
- 📱 **响应式设计** - 适配各种设备屏幕
- 💾 **本地存储** - 数据存储在浏览器本地，无需服务器

## 技术栈

- **前端**: HTML5, CSS3, JavaScript (ES6+)
- **存储**: LocalStorage
- **加密**: Web Crypto API (SHA-256)
- **架构**: 模块化设计，分离关注点

## 文件结构

```
├── index.html              # 主页面
├── styles/
│   └── main.css           # 样式文件
├── js/

│   ├── userManager.js     # 用户管理模块
│   ├── toolManager.js     # 工具管理模块
│   └── app.js            # 主应用逻辑
└── README.md             # 项目说明
```

## 功能说明

### 普通用户功能
- 查看可用工具列表
- 使用各种工具
- 退出登录

### 管理员功能
- 所有普通用户功能
- 添加、编辑、删除工具
- 管理用户账户
- 重置用户密码
- 查看系统日志

### 用户管理
- 创建新用户（自动生成临时密码）
- 重置用户密码
- 切换用户角色（管理员/普通用户）
- 强制用户改密
- 删除用户账户

## 安全特性

- 密码使用SHA-256哈希存储
- 临时密码机制，首次登录强制改密
- 会话管理，页面关闭自动退出
- 会话超时保护（24小时）
- 活动状态监控

## 开发说明

### 添加新工具
管理员可以通过界面添加工具，或直接修改 `js/toolManager.js` 中的默认工具列表。

### 自定义样式
修改 `styles/main.css` 中的CSS变量来调整主题色彩。

### 扩展功能
项目采用模块化设计，可以轻松扩展新功能：
- 在 `js/` 目录下创建新的模块文件
- 在 `index.html` 中引入新的脚本
- 在 `app.js` 中集成新模块
